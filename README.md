
The system distinguishes between:

```text
VERIFIED
INFERRED
UNKNOWN
```

Missing information should remain missing.

The system should never silently convert:

```text
UNKNOWN
```

into:

```text
MADE-UP
```

because hallucinated business information becomes significantly less amusing when a real customer sees it on their website.

# 12 // SITEFORGE — STATE ISOLATION

A critical testing requirement is ensuring one business execution does not contaminate another.

```text
A → B → A → C
```

Expected:

```text
A DATA ≠ B DATA
B DATA ≠ C DATA
A DATA ≠ C DATA
```

Isolation verification:

```text
PLACE ID ISOLATION      :: PASS
BUSINESS NAME ISOLATION :: PASS
```

This matters because state leakage in an AI pipeline can produce extremely convincing garbage.

```text

DOES STATE LEAK?

DOES THE SYSTEM RECOVER?
```

```text

     ↓

     ↓

     ↓

     ↓
```

### Failure Cases

```text

DUPLICATE INPUT
UNEXPECTED INPUT
```
